# dependencies.txt — Ubuntu 24.04 (noble) build dependencies for ImmortalWrt
#
# 目标运行时 = Ubuntu 24.04 LTS (noble)。CI 与本地统一在这一个发行版上验证，
# 因此本清单里的每一个包名都必须在 noble 的 main + universe 索引中真实存在。
#
# 相对 Ubuntu 22.04 (jammy) 的三处包名变更（jammy 的旧名在 noble 已不存在）：
#   gnutls-dev  -> libgnutls28-dev
#   libz-dev    -> zlib1g-dev
#   mkisofs     -> xorriso（genisoimage 在 noble 仍可用，见下方 rtfw-builder 段）
#
# 关于 Clang/LLVM 的版本取舍：
#   Ubuntu 自带的默认版本与上游要求的 18 冲突，故显式装 18 全套。
#   jammy 默认 clang 是 14，内核 6.18 起的 BPF 头文件编译要求
#   "Minimum Clang version: 18.0.0"（早期是 15），会在 build 阶段直接中止；
#   noble 默认已是 18，但本清单仍显式列出 18 全套，以免依赖 metapackage 漂移。
#
# upx 不在本清单中：noble 的 upx-ucl 包版本落后于上游要求，
# 改由 scripts/build/steps/install-deps.sh 的 install_extra_toolchains() 以官方 release 二进制落地。
